# AVORA Roadmap Snapshot — Starter Foundation

## Phase 0 — Foundation
- One Flutter codebase for Android + iOS
- GitHub version control
- Firebase project
- Stable package ID
- Automated Android debug builds
- Configuration-driven architecture

## Phase 1 — Account & Social
- Email/social sign-in where practical
- Password reset
- Profile, avatar, gender, country, DOB, bio
- Friends, follow/followers/following, visitors
- Transaction PIN with recovery

## Phase 2 — Rooms
- Voice rooms, mic seats, host/mod permissions
- Room themes, public/private/approval modes
- Music and per-user sound/effect controls
- Room history, rejoin, favorites

## Phase 3 — Economy
- Recharge coins
- Gift spend / receiver value
- Diamond/coin exchange by configurable rate
- Salary/earnings balances
- Seller/agent inventory
- Immutable ledger + reversals
- No direct hidden balance edits

## Phase 4 — Business Roles
- Owner-only global console
- Country managers with scoped permissions
- BD, agency, host, seller, agent roles
- Automatic commissions, salary and rewards

## Phase 5 — Trust, Safety & Recovery
- Device/account risk controls
- Verification and reward eligibility
- Moderation and reporting
- Kill switches
- Incident impact analysis
- Reconciliation and compensating transactions

## Phase 6 — Scale
- Queue/event-driven processing
- Idempotent recharge/reward/salary jobs
- Rate limits
- Monitoring/alerts
- Load testing
- Horizontal scaling
